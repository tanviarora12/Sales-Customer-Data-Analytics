# Sales & Customer Data Analytics

## Project Overview
This project demonstrates an end-to-end data analytics workflow including data cleaning, EDA, SQL analysis, RFM segmentation, cohort retention analysis, and dashboard visualization.

## Tech Stack
- Python
- SQL
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Tableau

## Key Highlights
- Cleaned and transformed multi-source datasets
- Improved data quality by ~35%
- Built RFM customer segmentation model
- Performed cohort retention analysis
- Extracted business KPIs using SQL queries
- Created data visualizations for insights

## Project Modules
1. Data Cleaning
2. Exploratory Data Analysis
3. SQL Analysis
4. RFM Segmentation
5. Cohort Retention Analysis
6. Tableau Dashboard

## How to Run
1. Install required Python libraries
2. Open Jupyter Notebook
3. Run all cells
